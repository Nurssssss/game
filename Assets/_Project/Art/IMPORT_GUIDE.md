# Импорт внешних ассетов: пошаговая инструкция

Проект: Unity **6000.5.5f1**, рендеринг **URP 17.5.0**, целевая платформа
Windows 64-bit.

Это важно: ассеты для встроенного рендера (Built-in) в URP выглядят
**розовыми** — их материалы нужно конвертировать. Шаг 5 решает эту проблему.

---

## Шаг 0. Установите Git LFS (один раз)

Без него 3D-модели и текстуры попадут в историю git напрямую и раздуют
репозиторий безвозвратно. Требование NFR-014.

```bash
brew install git-lfs
cd /Users/nursultan/gameDev/FirstProject
git lfs install
git lfs track "*.fbx" "*.png" "*.jpg" "*.tga" "*.hdr" "*.exr" "*.wav" "*.ogg"
git add .gitattributes
git commit -m "Включён Git LFS для бинарных ассетов"
```

Файл `.gitattributes` в проекте уже настроен — команда `git lfs track`
только зарегистрирует фильтры.

---

## Шаг 1. Скачайте наборы

Начните с одного набора, а не всех сразу: проверите процесс на малом.

**Рекомендую для старта — Kenney City Kit:**

1. Откройте <https://kenney.nl/assets/city-kit-commercial>
2. Нажмите **Download** (бесплатно, регистрация не нужна)
3. Там же возьмите **City Kit (Suburban)** и **City Kit (Roads)**

Почему именно Kenney:

- лицензия **CC0** — можно в коммерческом проекте без указания автора;
- low-poly, укладывается в бюджет отрисовки (NFR-001);
- единый стиль между наборами — город не будет выглядеть лоскутным;
- есть FBX и OBJ, оба читаются Unity.

**Небо — Poly Haven:**

1. Откройте <https://polyhaven.com/hdris/skies>
2. Выберите ясное дневное небо, скачайте **2K HDR** (4K и выше не нужны,
   это лишняя память — NFR-005)

---

## Шаг 2. Проверьте лицензию

**До импорта**, а не после. Откройте страницу набора и найдите строку с
лицензией. Убедитесь, что это CC0, CC-BY или Asset Store EULA.

Если лицензия не указана явно — **не используйте ассет.** По п. 11 ТЗ в
сборку не попадают ассеты без подтверждённого права.

---

## Шаг 3. Распакуйте в правильную папку

Папки уже созданы:

```
Assets/_Project/Art/External/
├── Buildings/     дома
├── Roads/         дороги, перекрёстки, тротуары
├── Props/         фонари, скамейки, урны, деревья
├── Furniture/     мебель для квартиры
├── Textures/      PBR-текстуры
└── Skyboxes/      HDRI-небо
```

Распакуйте архив и **перетащите папку с моделями** в нужную категорию
прямо в окне Project внутри Unity. Копировать через Finder тоже можно,
но тогда переключитесь в Unity и дождитесь импорта.

Из архивов Kenney нужна папка **Models/FBX** — папки с превью, исходниками
Blender и Isometric-спрайтами не нужны, они только занимают место.

---

## Шаг 4. Запишите источник в реестр

Откройте `Assets/_Project/Art/ASSET_SOURCES.md` и добавьте строку в таблицу
«Импортированные наборы». Пример:

```
| Art/External/Buildings/KenneyCityCommercial | https://kenney.nl/assets/city-kit-commercial | Kenney | CC0 | не требуется | 2026-07-27 | Нурсултан |
```

Это не бюрократия: без реестра нельзя доказать право на ассет, если
возникнет вопрос при публикации.

---

## Шаг 5. Конвертируйте материалы в URP

**Самый важный шаг.** Если пропустить — модели будут розовыми.

**Быстрый способ** — выделите импортированные модели и материалы в Project,
затем: **Edit → Rendering → Materials → Convert Selected Built-In Materials
to Current SRP**.

**Полный способ** (если быстрый не помог):

1. В верхнем меню: **Window → Rendering → Render Pipeline Converter**
2. В списке отметьте **Built-in to URP** → **Material Upgrade**
3. Нажмите **Initialize Converter**, затем **Convert Assets**

Если после конвертации какая-то модель всё ещё розовая:

- выделите её материал в Project;
- в Inspector сверху смените **Shader** на `Universal Render Pipeline/Lit`;
- перетащите текстуру в слот **Base Map**.

---

## Шаг 6. Настройте импорт моделей

Выделите импортированные FBX (можно все сразу) и в Inspector:

**Вкладка Model:**
- **Scale Factor** — у Kenney обычно `1`, но проверьте: дом должен быть
  выше персонажа (персонаж 1.8 м). Если модель крошечная — поставьте `100`
- **Mesh Compression** — `Medium` (экономит память, качество не страдает)
- **Read/Write Enabled** — снять галочку (иначе меш дублируется в памяти)
- **Generate Colliders** — поставить для домов и дорог

**Вкладка Materials:**
- **Material Creation Mode** — `Standard`
- **Location** — `Use External Materials`

Нажмите **Apply**.

---

## Шаг 7. Настройте текстуры

Выделите все текстуры в `Art/External/Textures` и в Inspector:

- **Max Size** — `1024` для стен и дорог, `2048` только для крупных
  поверхностей крупным планом
- **Compression** — `Normal Quality`
- **Generate Mip Maps** — включено (иначе дальние поверхности будут
  «шуметь»)

Это прямо влияет на NFR-005 — бюджет памяти.

Напишите, какие наборы поставили и как называются папки. Я:

- напишу генератор расстановки: дома встанут по кварталам, дороги по

Расстановку вручную делать не нужно — это моя часть.

## Что при этом сломается (и почему это нормально)

Текущая сцена собирается генератором с нуля при каждом запуске команды
**Qonaev Life → Собрать тестовую сцену**. Когда добавите ассеты, я обновлю
генератор — и он начнёт ставить ваши модели вместо процедурных коробок.

Пока генератор не обновлён, импортированные ассеты просто лежат в проекте
и ни на что не влияют. Ничего не сломается.

## Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Модель розовая | Материал для Built-in | Шаг 5 |
| Модель размером с пиксель | Единицы измерения | Scale Factor = 100 |
| Персонаж проходит сквозь дом | Нет коллайдера | Generate Colliders в Model |
| Текстура мыльная вблизи | Max Size слишком мал | Поднять до 2048 |
| Unity тормозит после импорта | Идёт импорт и сжатие | Дождаться конца |
| Тёмные модели | Нет освещения на сцене | Уже настроено, пересоберите сцену |
