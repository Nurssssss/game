# Реестр источников внешних ассетов

Требование п. 11 ТЗ: команда обязана вести реестр источников каждого внешнего
ассета — фотографии, карты, аудиозаписи, логотипы, названия компаний, шрифты,
3D-модели и текстовые материалы. **В сборку не попадают ассеты без
подтверждённого права использования.**

Каждый импортированный набор добавляется в таблицу ниже до первого коммита.

## Как заполнять

| Поле | Что писать |
|---|---|
| Ассет | Папка в проекте, например `Art/External/KenneyCityKit` |
| Источник | Прямая ссылка на страницу загрузки |
| Автор | Как указан правообладателем |
| Лицензия | Точное название: CC0, CC-BY 4.0, Unity Asset Store EULA |
| Атрибуция | Требуется ли указание автора в титрах |
| Дата | Когда скачано |
| Проверил | Кто подтвердил право использования |

## Проверенные безопасные источники

Ниже — наборы, лицензии которых допускают использование в коммерческом
проекте. Ссылки нужно открыть и убедиться, что лицензия не изменилась:
условия правообладатель может поменять в любой момент.

### CC0 — можно всё, атрибуция не требуется

| Набор | Что внутри | Ссылка |
|---|---|---|
| Kenney City Kit (Commercial / Suburban / Roads) | Low-poly дома, дороги, перекрёстки, тротуары | kenney.nl/assets |
| Kenney Furniture Kit | Мебель для интерьера квартиры (FR-055) | kenney.nl/assets |
| Poly Haven — HDRIs | Небо для скайбокса и отражений | polyhaven.com/hdris |
| Poly Haven — Textures | PBR-текстуры асфальта, бетона, кирпича | polyhaven.com/textures |
| Poly Haven — Models | Уличные объекты: скамейки, урны, столбы | polyhaven.com/models |

CC0 означает передачу в общественное достояние: указывать автора
не обязательно, но это хороший тон.

### CC-BY — можно, но атрибуция обязательна

| Набор | Условие |
|---|---|
| Quaternius (Ultimate Modular Buildings) | Указать автора в титрах |
| Sketchfab с фильтром CC-BY | Указать автора и ссылку на модель |

При использовании CC-BY имя автора **обязано** попасть в титры игры,
иначе лицензия нарушена.

### Требует осторожности

| Источник | Проблема |
|---|---|
| Unity Asset Store (бесплатные) | Лицензия EULA привязана к аккаунту. Другой разработчик в команде не может использовать ваш скачанный ассет — нужна своя копия. |
| Google Poly, случайные модели из интернета | Лицензия часто неизвестна. **Не использовать.** |
| Модели реальных зданий Конаева со спутниковых карт | Права на исходные данные. Требует отдельного согласования (п. 11 ТЗ). |

## Запрещено

По п. 11 ТЗ в сборку не попадают:

- ассеты без подтверждённого права использования;
- изображения реальных людей без законного основания;
- реальные номера автомобилей и частные адреса;
- логотипы и названия существующих компаний без разрешения.

Реальные городские ориентиры Конаева можно использовать только после
проверки прав на исходные данные, изображения, бренды и вывески (п. 2.1 ТЗ).
